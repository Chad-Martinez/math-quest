# Game design

Pick a world on the adventure map. Each world has a short quest with a visible progress track. A correct answer earns one star and explains the relationship. Retry as needed or follow hints to a worked example. Completing all challenges reveals the world’s quest outcome, then offers the map and replay.

The shared interaction follows Read → Find → Draw → Solve → Check as needed. Each challenge focuses on one response at a time. Two-step stories ask for the intermediate quantity before the final response. The drawing pad supports pointer input and is optional.
