# Release scope

Dinosaur Island: The Lost Egg, Chapter 1, is the active playtest. [Release configuration](../js/release.js) and [bootstrap](../js/bootstrap.js) select the Chapter 1 experience. The wider curriculum and legacy adventures remain available for local development through the flag. Leave Chapter 2, Megalodon’s major appearance, picture graphs, tally charts and additional worlds out of Chapter 1 navigation. Keep the game static and progress local.

| Production scene | Role in Chapter 1 |
| --- | --- |
| 01 Welcome | Entry and resume |
| 02 The Missing Egg | Story introduction |
| 03 Adventure Map | Empty Nest start, travel, five math stops and an unnumbered break |
| 04 Brachiosaurus Berry Grove | Math stop 1 |
| 05 Velociraptor Trail | Math stop 2 |
| 06 Triceratops Picnic Clearing | Math stop 3 |
| 07 Stegosaurus Wiggle Meadow | Optional movement |
| 08 Mosasaurus Crystal Lagoon | Math stop 4 |
| 09 Ankylosaurus Crystal Cave | Math stop 5 |
| 10 Egg Discovery | Existing Mosasaurus clue leads to finding the unhatched egg |
| 11 Chapter Celebration | Chapter reward and replay or return home |

These are production scene numbers. The map and curriculum count only math stops. The First Playable already includes the five activities, break, discovery and celebration. Each remains available while its dedicated revision awaits a scene kit and authorization. See [approval and deployment status](approval-register.md) before altering approved work.

Pages builds from `main` at the repository root. Use a development branch for review. With explicit publishing approval, merge, wait for the Pages build for the actual merge commit, and smoke-test the hosted build under `/math-quest/`. Record which user flows and devices were checked.
