# Parent Coach

Teaching tips appears on every challenge. The panel opens with a short prompt to try with the learner. Expand **Show demonstration** for steps using the current quantities, or **More ways to help** for a prerequisite, a response to a possible misunderstanding, an accommodation, and an activity with physical objects. The panel is a convenience on a shared screen.

**Reveal worked solution** deliberately shows the answer and explanation inside the panel. Closing returns to the same question, including the draft response, drawing, math model, and progress. **I helped with this problem** records instructional help before the problem is solved. **Try a similar problem** queues a fresh problem of the same template immediately after the current one. Guided lessons already include their own sequenced practice and later review. Each regular adventure has one shared slot for this follow-up or the automatic follow-up after a worked hint. Numeric follow-ups prefer a different answer. For formats such as true/false, the underlying numbers must change and the answer class may repeat.

## Coverage and content

The template catalog owns the math. Guides use named parameters, model data, or chart rows from the generated item. The worked solution uses the same validated answer and equation as the child view. Adding a new template requires a contextual guide. A missing guide displays an unavailable notice and fails the coverage test. Coach demonstrations are parent-led scripts. A full interactive workspace and separate teaching stages are later work.

## Local evidence

Phase 1 keeps up to 100 finalized item summaries in browser storage. A summary records generated IDs, the adventure and template, the outcome, final-response attempt count and first-attempt correctness, and whether supports were used. Valid final submissions are counted. Blank or invalid input and intermediate-step submissions are excluded. Instructional hint levels are kept separately for each step. Opening the panel, using math tools or drawing, and narration leave independent eligibility intact. An instructional hint, marked parent help, or revealing the answer before solving makes a correct result assisted. Advancing after the child’s worked hint has its own outcome. Reviewing a solution after the outcome is recorded leaves that outcome intact.

The app stores no names, response text, images, or playback data. Ending an unfinished item without solving or reaching a worked example leaves no record for that item. Local evidence follows the existing whole-game and adventure reset controls. The browser's storage limits still apply. Coach evidence is an observation about recorded actions and should never be interpreted as a diagnosis or proof of mastery.
